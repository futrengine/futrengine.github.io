# Instagram Downloader (Frontend)
Download Instagram Posts, Reels, and Stories (No Music).

## ✅ Features
- Works with Instagram links
- Downloads photo or video content
- Animated UI with background music
- Uses free Render backend with CORS proxy

## 🚀 How to Deploy
1. Upload files to GitHub repo
2. Enable GitHub Pages in Settings
3. Share your link (e.g., `https://yourusername.github.io/insta-downloader/`)
